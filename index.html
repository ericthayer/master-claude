Skills

Saved instructions Claude follows for a repeatable job. Each one is a single SKILL.md file.

  • spec-to-component

    Turn a design-system component request or ticket into a testable spec, then a plan, then an implementation with a11y and token gates.

  • design-token-audit

    Audit a codebase or diff for design-token drift: hard-coded values, unused or duplicate tokens, theme gaps and contrast failures.

  • kaizen-retro

    Run a weekly kaizen retro on Claude workflows: find repeated prompts, blind approvals and slow steps, log metrics, and set next week's hypothesis.

spec-to-component fills in the component spec template.
